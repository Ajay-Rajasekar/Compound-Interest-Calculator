# Compound Interest Calculator
A Python script that calculates compound interest based on user-provided principal, interest rate, and time.
## FEATURES
* Input Validation: Uses while loops to ensure users cannot enter negative values for the principal, rate, or time parameters.
* Clean Output: Utilizes Python string formatting ({amount:,.2f}) to automatically apply comma separators and lock the final calculated amount to two decimal places.
* Accurate Math: Leverages the built-in pow() function for precise exponential calculations.
